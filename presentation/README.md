### 🎯 Presentation Overview

This presentation explains how Artificial Intelligence can support cybersecurity by helping detect suspicious activities, analyze potential threats, and assist in preventing cyber attacks.

The presentation is accompanied by the **AI Cyber Threat Analyzer** live demonstration included in this repository.

### 🚀 Live Demo

During the presentation, the project demonstrates two scenarios:

- Suspicious log file → Threat detected
- Normal log file → Safe activity detected

The live analyzer displays threat indicators, risk score, matched evidence, and security recommendations.
