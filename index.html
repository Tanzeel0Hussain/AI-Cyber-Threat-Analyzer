ABOUT THE PROJECT

AI Cyber Threat Analyzer

AI Cyber Threat Analyzer is an educational cybersecurity demonstration created to show how security logs can be inspected for suspicious patterns and threat indicators.

This version uses browser-side rule-based analysis and is designed as a concept demonstration for the topic “AI in Cybersecurity: Detecting and Preventing Cyber Attacks.”
